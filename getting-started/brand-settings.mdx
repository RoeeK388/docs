Your brand settings are the foundation for how Jurni styles new experiences. Configure them before you start building so your pages use the correct logo, colors, typography, and visual system from the beginning.

<Note>
  Brand settings live under **Settings → Brand**. Jurni recommends completing these settings before building pages.
</Note>

## Brand logo

Use the **Brand Logo URL** field to add your primary brand logo.

1. Go to **Settings → Brand**.
2. Find **Brand Logo URL**.
3. Paste the URL for your logo.
4. Click **Save Changes**.

Use a high-quality logo asset that is suitable for use across your landing pages and shopping experiences.

## Brand colors

Configure the core colors Jurni should use when styling your experiences.

1. Open **Settings → Brand**.
2. Select each color you want to configure.
3. Enter the brand's HEX value, or use the color picker to select the color on screen.
4. Click **Save Changes**.

These colors become part of the brand system Jurni can use when creating and styling experiences.

## Border radius

Set the default corner radius used across cards and other interface elements.

1. Find the **Border Radius** settings under **Settings → Brand**.
2. Choose the pixel value for each applicable element.
3. Click **Save Changes**.

This helps keep cards, buttons, and other UI elements visually consistent with your storefront.

## Typography

Review and configure your fonts for both desktop and mobile.

1. Open the **Typography** section under **Settings → Brand**.
2. Configure the appropriate fonts and font variants.
3. Review both **Desktop** and **Mobile** typography settings.
4. Click **Save Changes**.

Make sure all required font variants are configured. Missing font variants can cause substitutions or inconsistent typography when experiences are built or imported.

## Set up your brand before importing from Figma

If you plan to build from a Figma file, configure your Jurni brand settings first. At minimum, review:

- Fonts and font variants
- Colors
- Border radius
- Button typography and defaults

Jurni uses your brand system on top of the content and structure imported from Figma.

<Warning>
  Each experience is created with its own copy of your shop-level brand settings. Changing the shop-level brand settings later does **not** automatically update experiences that already exist.
</Warning>

If an existing experience needs to reflect new brand settings, update that experience's theme directly.

## Using brand tokens in experiences

After an experience is created, review its theme — especially typography. Use brand tokens for text wherever possible so your pages stay consistent with the system configured at the shop level.

Reserve custom font styling for cases where it is genuinely needed rather than overriding the brand system throughout the page.

## Before you start building

Confirm the following before creating your first experience:

- Your logo is correct and saved
- Brand colors match your approved palette
- Border radius values match your visual system
- Desktop and mobile typography are configured
- Required font variants are available
- Button styling matches your brand

Getting these settings right first reduces manual styling and rework across future experiences.

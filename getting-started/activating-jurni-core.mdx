Jurni Core connects a **Shopify Online Store** to Jurni's tracking and attribution layer. It runs on the Shopify storefront so a shopper who moves from a Jurni page into Shopify can keep the Jurni session, visit, experiment, and cart context needed for downstream measurement.

<Warning>
  If Jurni Core is not active on a Shopify Online Store, traffic can still reach a Jurni page, but Jurni may lose the storefront/cart evidence required to connect later Shopify activity and orders back to the correct Jurni visit.
</Warning>

## When this setup applies

Use this activation flow when the shopper-facing store is a standard **Shopify Online Store** using a Shopify theme.

Do **not** use this theme-app-embed setup as the instructions for:

- a Shopify Headless storefront
- a fully non-Shopify storefront

Those environments load Jurni's tracking integration differently. See [Supported commerce platforms](/getting-started/choose-your-setup) for the instructions that match your existing storefront.

## Activate Jurni Core

<Steps>
  <Step title="Open Jurni settings">
    In Jurni, open the account/setup area and find **Activate Jurni Core**.
  </Step>
  <Step title="Open Shopify">
    Use the activation action to open the Shopify theme editor for the connected store.
  </Step>
  <Step title="Enable the Jurni Core app embed">
    Enable Jurni Core in the theme/app-embed settings for the active theme.
  </Step>
  <Step title="Save the Shopify theme">
    Save the change in Shopify, then return to Jurni and confirm the Core status is active.
  </Step>
</Steps>

## What Jurni Core does

The current Shopify integration participates in the journey by helping Jurni:

- maintain the anonymous Jurni session on the Shopify storefront
- initialize/continue visit context
- read experiment parameters such as `jurni_ab_test_id` and `jurni_ab_variant_id`
- connect Shopify cart activity with the Jurni session/visit
- preserve Jurni attribution data on the Shopify cart where available
- capture checkout evidence through the Shopify integration/pixel path
- connect eligible Shopify orders back to the most recent valid Jurni visit

Jurni's current order-attribution model uses Jurni visit/cart/checkout evidence within its attribution window. Shopify's **Sales channel** label is not the rule used to decide which Jurni page or experiment receives credit.

## Jurni-hosted pages vs. Shopify Pages

Core is especially important when a shopper starts on a Jurni-hosted page—such as an app-proxy or custom-subdomain URL—and then continues into the Shopify storefront/checkout.

Native **Shopify Pages** are served inside the Shopify theme itself. They still rely on the Shopify/Jurni integration for Jurni measurement, but the page rendering and third-party-script environment is different from Jurni-hosted pages.

## Verify the installation

After activating Core:

1. Open the live Shopify storefront in a new browser session.
2. Enter through a Jurni page or Smart Link.
3. Continue into Shopify and add a product to cart.
4. If you are validating attribution, complete a test order.
5. Confirm the Jurni session/experiment and order appear under the expected page or variant.

## Troubleshooting

If Jurni still shows Core as inactive:

- confirm you enabled the app embed in the **active** Shopify theme
- save the theme after enabling it
- make sure you are looking at the Shopify store connected to the current Jurni workspace
- check whether a theme change or duplication caused the app embed to be disabled in the new active theme

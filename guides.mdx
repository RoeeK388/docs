## Which surface should I use?

| You're asking… | Go to… |
| --- | --- |
| “How do I configure this exact setting?” | **Help Center** |
| “I know the job I need to do—which articles matter?” | **Guides** |
| “What is the best workflow for this campaign?” | **Academy** |
| “What changed in the product?” | **Changelog** |

Academy teaches the workflow. The Help Center stays the source of truth for current product setup and behavior.

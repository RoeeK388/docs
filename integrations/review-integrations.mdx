Connect the review platform your brand already uses, then place its widget on your page. **Saving an account connection does not automatically add a review section to every experience.**

## Find your provider

| Provider | Value needed in Settings | Additional page-level configuration |
| --- | --- | --- |
| [Okendo](/integrations/okendo) | Subscriber ID / User ID | All, product, or group reviews; the matching product or Group ID. |
| [Junip](/integrations/junip) | Store Key | Review scope and the matching product where applicable. |
| [Yotpo](/integrations/yotpo) | App Key | Widget Instance ID and review scope/product. |
| [Judge.me](/integrations/judge-me) | Public API Token | Supported widget type and product; platform-independent setup for Jurni-hosted pages. |
| [Stamped](/integrations/stamped) | Store Hash and API Public Key | Product for the main review widget. |
| [Trustpilot](/integrations/trustpilot) | Business Unit ID | Widget Template ID. |
| [REVIEWS.io](/integrations/reviews-io) | Store ID / url_key | Rating or full widget and the product's REVIEWS.io SKU. |
| [Bazaarvoice](/integrations/bazaarvoice) | Client Name | Product mapping and compatibility with your Bazaarvoice deployment. |

Each linked guide explains where to find the exact values. These identifiers are not interchangeable: a product ID is not an account ID, and a widget ID is not an API key.

## Complete the two-step setup

**Connect the account:** open **Settings → Integrations → Reviews & Pop-ups**, enable the provider, enter the required values, and select **Save Changes** on its card.

**Place the reviews:** open the page editor's **Integrations** panel, add the provider's section, select the widget, and complete its settings. Save the page and verify it on the published destination.

Use [Configure review widgets](/integrations/review-widgets) for the page workflow.

## What stays in the review platform?

Manage review collection, approval, product feeds, and the provider's own widget design there. Jurni provides the supported placement and configuration; it does not migrate your reviews or automatically connect every product in that company's suite.

For example, a Yotpo Reviews connection does not configure its Loyalty product. An Okendo review widget does not automatically implement a custom review drawer or quiz.

## Check the publishing environment

On Jurni-hosted pages, the provider needs the Jurni connection and placement. On **Shopify Pages**, a provider may also be loaded by the Shopify theme or app. Check the final `/pages/` URL for both missing and duplicate widgets.

For a headless or non-Shopify catalog, verify product-ID/SKU compatibility with the Jurni team instead of assuming a Shopify-specific widget mapping applies unchanged.

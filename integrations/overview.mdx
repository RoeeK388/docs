Start with the job you need the integration to do. **Connecting an account, placing a widget, and configuring tracking are different tasks.** Use the provider guide for the exact values and setup steps.

## Track visits and conversions

| Tool | Use it for |
| --- | --- |
| [Google Analytics 4](/integrations/google-analytics) | Website activity and campaign analysis in your GA4 property. |
| [Google Tag Manager](/integrations/gtm) | Loading your team's tag container; tags and event mappings are configured separately. |
| [Meta Pixel](/integrations/meta-pixel) | Supported browser events for the website pixel used by Meta advertising. |
| [TikTok Pixel](/integrations/tiktok) | Supported browser events for the TikTok website data source. |
| [Northbeam](/integrations/northbeam) | Including Jurni pages in your Northbeam measurement setup. |
| [Axon](/integrations/axon) | Axon/AppLovin browser-pixel tracking. |
| [Polar Analytics](/integrations/polar-analytics) | Supported page events for the Shopify store connected to Polar. |
| [Triple Whale](/integrations/triple-whale) | Loading Triple Pixel for the connected Shopify shop. |
| [Blotout EdgeTag](/integrations/blotout) | Connecting the existing EdgeTag implementation agreed with your tracking team. |
| [Shopify Analytics](/getting-started/shopify-analytics) | The supported Shopify analytics setup for Jurni-hosted pages. |

Configure these from **Settings → Integrations → Data Integrations**. Most tracking IDs share one **Save Changes** action; Shopify Analytics and Triple Whale have their own controls.

## Display reviews, collect leads, and show pop-ups

For reviews, connect the provider in **Settings → Integrations → Reviews & Pop-ups**, then add its widget from the **editor → Integrations** panel. Some widgets need another identifier after the account is connected.

[Okendo](/integrations/okendo) · [Junip](/integrations/junip) · [Yotpo](/integrations/yotpo) · [Judge.me](/integrations/judge-me) · [Stamped](/integrations/stamped) · [Trustpilot](/integrations/trustpilot) · [REVIEWS.io](/integrations/reviews-io) · [Bazaarvoice](/integrations/bazaarvoice)

For lead collection, use [Klaviyo](/integrations/klaviyo) or [Postscript](/integrations/postscript). Use [Alia](/integrations/alia) for its pop-up connection. Embedded forms are placements on the page; [pop-up controls](/build/page-popups) are separate experience-level switches.

## Connect ad accounts, design tools, and your team

[Meta Ads](/integrations/meta-ads) connects the advertising account and supports the related ad-data workflows. **It does not replace Meta Pixel setup.**

[Figma](/building-funnels/figma-file) connects design references to your page-building workflow. [Slack](/integrations/connect-slack) connects the workspace; [scheduled reports](/notifications/slack-reports) are configured separately.

[Affiliatly and Bix Grow](/integrations/affiliate-tools) support the relevant affiliate setup; [creator records](/integrations/manage-creators) hold the corresponding creator information.

## Complete the connection, not just the form

<Steps>
  <Step title="Get the right values">
    Open the provider guide and copy the required ID, URL, or public token from the correct brand account. Some connections use an authorization screen or a switch instead; do not create an API key unless the guide asks for it.
  </Step>
  <Step title="Configure Jurni">
    Save the account connection. For a widget, add and configure its page placement. For tracking, have your tracking owner check the required events and checkout connection.
  </Step>
  <Step title="Verify the published destination">
    Test the real page and shopper action. Check the expected review, signup, or event in the provider, not just the integration's enabled state.
  </Step>
</Steps>

## Shopify Pages and custom storefronts

**Shopify Pages** run in your theme, where some tools may already be installed. Verify the final page for missing or duplicate scripts. A working Jurni-hosted preview does not verify a Shopify theme placement.

For **headless or non-Shopify stores**, confirm catalog identifiers and downstream cart/checkout tracking with the Jurni team. A provider connection does not automatically configure your commerce integration.

For a tool not listed here, use [Custom Scripts](/integrations/custom-scripts) only when the implementation is appropriate, or contact the team about a custom integration.

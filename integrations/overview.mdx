Use **Settings → Integrations** to configure the external platforms that Jurni currently exposes in the merchant app. Different integrations use different connection methods—some use OAuth, some use IDs/URLs, and some are simple enable/disable integrations.

Do not assume every integration needs an API key or that the same credential type is used across vendors.

## Current integration areas

### Ad Integrations

The current **Ad Integrations** section connects **Meta Ads** accounts to Jurni. This is separate from entering a Meta Pixel ID for page tracking.

### Messaging

The current Messaging integration is **Slack**. Jurni supports more than one connected Slack workspace for a shop, subject to the user's Jurni permissions.

See [Connect Jurni to Slack](/integrations/connect-slack) for the installation and access model.

### Data Integrations

The current Data Integrations page includes the following tracking fields/integrations:

- **Meta Pixel IDs** — more than one Pixel ID can be configured
- **Google Tag Manager ID** — must use the `GTM-...` format
- **Google Analytics tag ID** — must use the `G-...` format
- **Blotout EdgeTag URL**
- **Axon Pixel ID**
- **Northbeam Pixel ID**
- **Polar Analytics Shopify URL**
- **TikTok Pixel ID**
- **Shopify Analytics** configuration
- **Triple Whale** enable/disable integration

<Info>
  Meta Ads account connection and Meta Pixel tracking are different integrations. Connecting a Meta ad account does not replace configuring the Pixel IDs you want Jurni pages to load.
</Info>

### Design

Jurni currently exposes a **Figma** connection for Figma-powered workflows. Connection and management are permission-controlled in Jurni.

### Affiliate Integrations

The current affiliate toggles are:

- **Affiliatly**
- **Bix Grow**

### Lifecycle, Widgets & Reviews

The current integration registry includes:

- **Klaviyo** — Company ID
- **Postscript** — Shop ID
- **Alia** — embed script URL
- **Junip** — Store Key
- **Stamped** — Store Hash + API Public Key
- **Trustpilot** — Business Unit ID
- **Okendo** — Subscriber ID (User ID)
- **Yotpo** — App Key
- **Judge.me** — Public API Token
- **Bazaarvoice** — Client Name
- **REVIEWS.io** — Store ID

The credential requested by Jurni is the credential shown in the integration card. For example, Jurni currently asks for a **Klaviyo Company ID**, not a Klaviyo private API key.

## Custom Scripts are separate

**Settings → Custom Scripts** is a separate system from the Integrations page. Use it for third-party browser code that does not have an appropriate native Jurni integration.

Custom Scripts support **All funnels**, **Only selected**, and **All except** targeting. Tracking scripts only run on live funnels, not Preview.

See [Custom Scripts](/integrations/custom-scripts) for the exact behavior and Shopify Pages limitation.

## Before connecting an integration

Identify what you actually need the integration to do:

- **Ad account data** → Meta Ads connection
- **Page/event tracking** → tracking pixel / GTM / GA configuration
- **Review widgets** → connect the matching review provider
- **Slack data access/reporting** → Slack integration + notification settings
- **Custom browser-side vendor** → Custom Scripts when appropriate

This distinction helps avoid duplicate installations—for example loading a Meta Pixel through both Jurni Data Integrations and GTM.

## Verify after setup

After saving an integration:

1. Test a **live** funnel, not only Preview.
2. Confirm the vendor/script loads only once.
3. Trigger the relevant customer action.
4. Verify the event/widget in the third-party platform.
5. If the page is a Shopify Page, verify the behavior separately because Shopify theme/app integrations and Jurni-hosted funnel integrations do not have identical loading paths.

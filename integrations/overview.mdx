Jurni connects to your existing DTC tech stack so you can keep the tools you already use. From review platforms and analytics pixels to email providers and custom scripts, every integration lives in one place: **Settings → Integrations**. This page covers the available categories, how to read status indicators, the two connection methods, and answers to common questions.

## Status Indicators

Every integration tile shows a status indicator so you can spot issues at a glance.

- **Active (green)** — The integration is connected and working.
- **Disconnected (red)** — The integration has not been set up yet or needs reconnection. This usually means a revoked or expired API key. Re-authenticate to resolve.

<Tip>
  Check the status of all integrations after major changes to your Shopify store or third-party accounts. Re-keying in one platform can break connections in another.
</Tip>

## Connection Methods

Integrations connect in one of two ways. Choose the method that matches the platform you are connecting.

<Steps>
  <Step title="OAuth">
    Click **Connect** and authorize Jurni in the third-party platform. Shopify and Slack use OAuth.
  </Step>
  <Step title="API Key">
    Paste a key or Measurement ID from the third-party platform into Jurni. GA4, Meta Pixel, Klaviyo, and review platforms use API keys.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Where to find common API keys and credentials">
    - **Yotpo** — Dashboard → Account Settings → Store Settings → API Key
    - **Okendo** — Dashboard → Settings → API
    - **Junip** — Dashboard → Settings → Integrations → API Key
    - **Stamped** — Dashboard → Settings → API Keys
    - **Trustpilot** — Business → Integrations → API
    - **Klaviyo** — Account → Settings → API Keys → Create Private Key
    - **Google Analytics 4** — Admin → Data Streams → select your stream → Measurement ID (format: `G-XXXXXXXXXX`)
    - **Meta Pixel** — Events Manager → select your pixel → Settings → Pixel ID
    - **Blot Out** — Site Settings → find the EdgeTag URL and paste it into Jurni
  </Accordion>

  <Accordion title="Key security guidelines">
    - Never share API keys in Slack, email, or any public channel.
    - Never commit API keys to version control.
    - If a key is compromised, regenerate it immediately in the third-party platform, then update it in **Jurni Settings → Integrations**.
    - Use Private API Keys for server-side integrations like Klaviyo. Public keys are safe for client-side widget display.
    - Rotate keys periodically as part of your team's security hygiene.
  </Accordion>
</AccordionGroup>

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Do I need all integrations connected before I can launch a funnel?">
    No. Shopify is the only required integration. You can launch funnels without review widgets, analytics, or email capture. Add integrations as your stack grows.
  </Accordion>

  <Accordion title="Can I connect multiple accounts for the same integration type?">
    Most integrations support one connected account at a time. If you need multi-account support, contact the Jurni team at [info@getjurni.ai](mailto:info@getjurni.ai) or via Slack.
  </Accordion>

  <Accordion title="What happens if an integration disconnects?">
    Jurni will show a red error status. Funnel pages will still load, but affected features (review widgets, pixel events, email capture) will stop working until the connection is restored.
  </Accordion>

  <Accordion title="What happens if I enter the wrong API key?">
    Jurni will show a red error status on that integration tile. The integration will not function until a valid key is entered and saved.
  </Accordion>

  <Accordion title="Do I need to update Jurni when I regenerate a key in a third-party platform?">
    Yes. Whenever you regenerate or rotate a key in a third-party platform, you must update that key in Jurni Settings → Integrations immediately or the integration will break.
  </Accordion>
</AccordionGroup>

Use this directory when Jurni asks for a connection value. **The provider guides include the full steps; this page tells you which value to look for.** Do not assume every integration needs an API key.

## Tracking

| Provider | Copy this | Find it here |
| --- | --- | --- |
| [GA4](/integrations/google-analytics) | Measurement ID beginning **G-** | Google Analytics → Admin → Data streams → web stream. |
| [GTM](/integrations/gtm) | Container ID beginning **GTM-** | Google Tag Manager → the web container's Workspace. |
| [Meta Pixel](/integrations/meta-pixel) | Website Pixel ID | Meta Events Manager → the intended website data source → details/Settings. |
| [TikTok](/integrations/tiktok) | Website Pixel ID | TikTok Ads Manager → Tools → Events Manager → pixel details. |

| [Axon](/integrations/axon) | Browser pixel Event Key | Axon's native JavaScript pixel instructions; the **AXON_EVENT_KEY** value. |
| [Blotout](/integrations/blotout) | Full HTTPS EdgeTag endpoint | Blotout → EdgeTag → Domains; confirm the correct endpoint with your implementation owner. |
| [Polar](/integrations/polar-analytics) | The connected store's **.myshopify.com** domain | Shopify → Settings → Domains; match the store connected in Polar. |

## Authorization screens and switches

[Meta Ads](/integrations/meta-ads), [Slack](/integrations/connect-slack), and [Figma](/building-funnels/figma-file) use the relevant connection/authorization flow. Use the account with access to the intended ad account, workspace, or design files.

[Affiliatly and Bix Grow](/integrations/affiliate-tools) use Jurni integration switches and the appropriate affiliate reference on the creator record. They are not generic API-key fields.

## Before you save

Confirm the value belongs to the correct brand account and matches the field—not a neighboring private key, variant ID, or unrelated widget ID. Save through the control shown on that integration, then test the actual page result.

Do not put account secrets in AI prompts, Custom Scripts, or screenshots. A browser script is visible to shoppers; only use identifiers explicitly intended for that integration path.

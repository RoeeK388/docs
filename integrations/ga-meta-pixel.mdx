## Which connection do I need?

Use **GA4** for website activity and campaign analysis in Google Analytics. Use **Meta Pixel** for the supported website events used by your Meta advertising setup. Some brands use both for different purposes.

If your tracking team already loads these tags through [Google Tag Manager](/integrations/gtm), review that installation before adding the same tag directly in Jurni.

**Connecting Meta Ads is different from configuring Meta Pixel.** The [Meta Ads connection](/integrations/meta-ads) grants access to an advertising account; it does not replace entering the website pixel used for page tracking.

## Verify the final destination

Test the actual published Jurni page, consent flow, and downstream checkout. Native Shopify Pages may already inherit tags from the theme or apps. Do not assume the same installation is needed twice.

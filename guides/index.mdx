## Start with a useful prompt

```text
CONTEXT
[Traffic source, audience, campaign angle, and what the visitor already knows]

GOAL
[The one outcome this page or section should support]

SOURCES
[Products, ads, media, URLs, screenshots, Figma, or AI Knowledge]

BUILD OR CHANGE
[Exactly what Jurni should create or edit]

KEEP
[Copy, products, sections, styling, and behavior that must remain unchanged]

DO NOT
[Claims, prices, offers, reviews, or functionality Jurni must not invent]

VERIFY
[What Jurni should check before the task is complete]
```

For more examples, open the [Jurni Prompt Library](/academy/prompt-library).

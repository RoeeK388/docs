After an experience is live, you can continue editing it in Jurni without treating every edit as an immediate production change. Use the publishing controls to decide when the latest version should become available to shoppers.

## Draft vs. live content

A live experience and the version you are currently editing can represent different states. This is useful when you need to prepare changes, review them with your team, or QA a new offer before updating the live page.

<Warning>
If a page is receiving paid traffic, test important edits before publishing the new version. A layout change, product change, or tracking change can affect both conversion and reporting.
</Warning>

## Update a live experience

<Steps>
  <Step title="Make your changes">
    Edit the experience and review it in the Jurni editor.
  </Step>
  <Step title="Preview and QA">
    Check desktop and mobile layouts, product behavior, cart behavior, links, and tracking.
  </Step>
  <Step title="Open publishing controls">
    Use the Publish menu to view the current destination and publishing state.
  </Step>
  <Step title="Publish the update">
    Update the live page so the latest version is served to shoppers.
  </Step>
</Steps>

## Shopify Pages

For experiences published as Shopify Pages, use the Shopify publishing flow to push the latest version to the existing page. Keep the same Shopify page handle when you want to update the existing URL rather than create a second page.

## Unpublish an experience

Unpublishing removes the Jurni experience from its live publishing destination. Before you unpublish a page receiving traffic:

- Check ads, emails, and links that still point to the URL.
- Update or pause any Smart Link routing to that page.
- If the page is part of an experiment, update the experiment destination first.
- Decide where traffic should go instead.

## Safer campaign shutdowns

For paid campaigns, it is often better to reroute traffic before removing a destination. Smart Links can help you change the destination behind a stable campaign URL without editing the ad itself.

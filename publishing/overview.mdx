Publishing determines **where the live Jurni page is served**. Smart Links determine **which URL you put in campaigns and where that traffic is routed**.

Those are related, but they are not the same thing.

## The three publishing paths

### 1. Jurni page on a custom subdomain

This is the standard branded Jurni-hosted setup for paid landing pages.

After you connect a domain such as `go.brand.com`, your live pages and Smart Links can use that domain.

Example page or Smart Link URL:

`https://go.brand.com/summer-offer`

There is no Jurni limit on the number of pages you can create on the connected subdomain.

### 2. Shopify app proxy

For a **Shopify Online Store** that has not connected a custom Jurni subdomain, Jurni uses the Shopify app proxy as the default root-domain route.

Example:

`https://brand.com/apps/jurni/summer-offer`

The page is still served by Jurni, but the shopper-facing URL stays on the Shopify store domain through the app proxy.

### 3. Native Shopify Pages

Shopify Online Store brands can optionally publish a Jurni page into a Shopify page template.

Example:

`https://brand.com/pages/summer-offer`

Jurni creates/uses a Shopify page template containing the Jurni app block, and each published page can have its own Shopify page handle.

This is a different runtime from a Jurni-hosted page: the page lives inside the Shopify theme environment and can inherit theme/app behavior that is already installed in Shopify.

## Smart Links are the campaign-facing layer

For paid traffic, we generally recommend putting a **Smart Link** in the ad rather than hard-coding a page destination directly.

A Smart Link can point to:

- one Jurni page
- a native Shopify Page
- a supported external URL
- an experiment that splits traffic across multiple destinations

You can later change the destination behind the Smart Link without replacing the Smart Link URL in the campaign.

<Info>
  If a custom Jurni subdomain is configured, Smart Links use that domain. For Shopify shops without a custom subdomain, the current fallback URL uses the Shopify app proxy path under `/apps/jurni/`.
</Info>

## Shopify vs. Headless / Non-Shopify

| Store setup | Jurni-hosted / custom-domain pages | Shopify app proxy | Native Shopify Pages |
| --- | --- | --- | --- |
| **Shopify Online Store** | Yes | Yes, when no custom Jurni subdomain is configured | Optional |
| **Shopify Headless** | Yes / implementation-specific | Do not assume the Online Store proxy/theme flow applies | No — Shopify Pages depend on Online Store theme templates |
| **Non-Shopify** | Yes / implementation-specific | No | No |

See [Choose Your Setup](/getting-started/choose-your-setup) before publishing if you are not on a standard Shopify Online Store.

## Which Shopify publishing method should I use?

Use **Jurni-hosted / custom subdomain or app proxy** when you want the normal Jurni page runtime and Jurni-managed page integrations.

Use **Shopify Pages** when you specifically need the page inside the Shopify theme environment—for example, to use a native `/pages/` URL or existing Shopify theme/app scripts.

Shopify Pages have their own compatibility and cart considerations, so review [Shopify Pages: When to Use Them and Limitations](/shopify-pages/limitations) before switching a live campaign.

## Before sending traffic

Test the exact live URL and publishing method you will use:

1. desktop and mobile layout
2. all primary links and buttons
3. Buy Box/product configuration
4. subscription and bundle behavior
5. cart and checkout
6. pixels and analytics
7. review/popup/widget integrations
8. consent behavior
9. Smart Link routing and URL parameters
10. purchase attribution

Publishing answers one simple question: **where should this campaign live when a customer clicks the link?**

Jurni supports more than one live destination. Choose the path based on the campaign and storefront—not because one URL format looks more “native.”

## Which publishing path should I use?

| If you want… | Start with… | Typical URL |
| --- | --- | --- |
| A Jurni-hosted campaign page using Jurni's standard storefront runtime | **Jurni-hosted page** | A branded Jurni URL after your custom subdomain is connected |
| A Jurni-hosted page on Shopify before a custom subdomain is connected | **Shopify app-proxy route** | `brand.com/apps/jurni/...` |
| The page to live inside the Shopify Online Store theme environment | **Shopify Pages** | `brand.com/pages/...` |
| A headless or non-Shopify storefront | **Your agreed custom setup** | Your team's domain / route |

<Tip>
  Start with the environment the page actually needs. A Smart Link can give the campaign a stable branded entry URL separately.
</Tip>

## Jurni-hosted pages

Use the Jurni-hosted path when the experience should run in Jurni's storefront environment.

For Shopify brands, the initial route can use Shopify's app-proxy path. After a custom Jurni subdomain is connected, you can use branded Jurni campaign URLs on that subdomain.

This is usually the simplest path for Jurni-hosted campaigns because the page uses the Jurni storefront, cart/integration setup, and tracking path configured for that shop.

[Set up a custom subdomain →](/getting-started/custom-subdomain)

## Shopify Pages

Use **Shopify Pages** when the experience specifically needs to live at a native Shopify `/pages/` URL and run inside the Shopify theme environment.

This can be useful when your team wants:

- a native Shopify Page URL;
- the store's theme header/footer or theme layout;
- Shopify theme/app scripts that belong to that environment.

But Shopify Pages are not simply the Jurni-hosted page with a different URL. The theme, cart, app scripts, and page width can behave differently.

Before moving a campaign there, check:

- [Shopify Pages setup](/shopify-pages/setup-publish)
- [Shopify Pages limitations](/shopify-pages/limitations)
- [Shopify Pages cart connection](/shopify-pages/cart-config)

## Headless and non-Shopify storefronts

If your storefront does not use Shopify Online Store as the frontend, use the publishing, cart, checkout, and tracking path agreed with the Jurni team.

A Shopify theme app block does not publish into a separate headless frontend. WooCommerce, Salesforce, or a custom storefront also does not automatically use Shopify Pages or the Jurni Shopify cart.

[Choose your setup →](/getting-started/choose-your-setup)

## Page URL vs. Smart Link

These have different jobs:

**Page URL** = where the experience itself is published.

**Smart Link** = the campaign-facing URL whose destination is managed in Jurni.

A campaign can use one Smart Link while the underlying destination changes later, or while that Smart Link becomes the entry point for an experiment.

Use a [Smart Link](/building-funnels/smart-links) when paid media, email, creators, QR codes, or experiments should have a stable entry URL.

For experiments, the Smart Link connected to the test is the URL that should receive experiment traffic.

## The marketer launch flow

<Steps>
  <Step title="Finish and review the page">
    Check copy, mobile/desktop layout, product or conversion path, and anything the campaign brief requires.
  </Step>
  <Step title="Publish to the right environment">
    Use Jurni-hosted publishing, Shopify Pages, or your agreed headless/custom path. Preview is not the final live environment.
  </Step>
  <Step title="Create or choose the campaign link">
    Use a Smart Link when you want a stable campaign URL you can manage centrally.
  </Step>
  <Step title="Test the exact URL you will send traffic to">
    Open the real campaign link and verify destination, purchase/conversion action, offer, integrations, tracking, consent, and mobile.
  </Step>
  <Step title="Launch and monitor">
    Once traffic is live, avoid casual routing or page changes that make results harder to interpret.
  </Step>
</Steps>

## Which one should I choose?

**Choose Jurni-hosted** when you want the standard Jurni campaign runtime and do not specifically need Shopify's theme environment.

**Choose Shopify Pages** when the `/pages/` URL and theme/app environment are part of the requirement.

**Choose the custom/headless path** when your storefront architecture requires it.

If the decision depends on a cart, consent, tracking, or theme app, test that dependency before changing a live campaign destination.

## Common problems

### My Shopify Page looks different from the Jurni editor

Start with [Shopify Page layout](/troubleshooting/shopify-page-layout) and [theme style conflicts](/troubleshooting/shopify-theme-style-conflicts). Native Shopify Pages run inside the store theme, which can add layout and style behavior that the Jurni-hosted page does not use.

### The wrong product or subscription reaches cart

Use [Product & Cart Issues](/troubleshooting/product-cart-issues). Check the real selected variant, selling plan, quantity, and purchase action rather than the visible label alone.

### My Meta / GA4 / Shopify numbers do not match Jurni

Start with [Analytics Differences](/troubleshooting/analytics-differences). Align the date range, traffic, session definitions, attribution, consent, and installation path before assuming an event is missing.

### I'm seeing duplicate pixel or GTM events

Use [Duplicate Tracking Events](/troubleshooting/duplicate-tracking-events). The most common pattern is the same tool loading through more than one path—for example Jurni plus the Shopify theme or GTM.

### My experiment traffic or sessions look wrong

Use [Experiment traffic troubleshooting](/experiments/traffic-troubleshoot) and [Experiment vs Experience Sessions](/troubleshooting/experiment-experience-sessions). Make sure the campaign actually enters through the experiment Smart Link and account for returning visitor assignment and Routing Rules.

### A Smart Link or page URL says the route is already in use

Use [URL Route Conflicts](/troubleshooting/url-route-conflict). Existing or archived records can reserve a route even when you do not immediately see an active campaign using it.

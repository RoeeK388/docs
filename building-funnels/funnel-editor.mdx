Open an experience from **Experiences** to build or edit its pages. Most work follows the same flow: **add sections → edit content and design → check mobile and desktop → preview and publish**.

## Find your way around

<CardGroup cols={3}>
  <Card title="Canvas" icon="monitor">
    Select the section, text, image, or button you want to change.
  </Card>

  <Card title="Left toolbar" icon="panel-left">
    Open AI, Section Library, Saved Sections, Layers, the theme panel, and Integrations.
  </Card>

  <Card title="Right panel" icon="sliders-horizontal">
    Change the content, style, or settings available for your selection.
  </Card>
</CardGroup>

## Build and edit your page

<Steps>
  <Step title="Arrange the sections">
    Use **Section Library** to add a layout, then **Layers** to select, rename, copy, reorder, hide, or delete sections. Use Saved Sections for an independent copy of an approved design, or Global Sections when the content should stay shared.
  </Step>
  <Step title="Make your changes">
    Select content on the canvas and edit it in the right panel. Use **AI** for changes that are easier to describe. Name the section and say what should stay unchanged.
  </Step>
  <Step title="Connect the actions">
    Check what buttons do—not just their labels. Connect the Buy Box to the correct product and add any forms or review widgets the page needs.
  </Step>
  <Step title="Check both screen sizes">
    Start in **Editing All Sizes**, then use **Editing Desktop Only** for desktop adjustments. Review both views after changes to layout, copy, or purchasing controls.
  </Step>
  <Step title="Save, review, and publish">
    Save your draft before sharing. Use a Preview Link for viewing or invite reviewers for comments. When ready, publish and test the campaign's actual destination.
  </Step>
</Steps>

<Note>
  Global Sections and shared product data can affect more than one page. Also read any save or publish prompt carefully: on an already published experience, entering comments with unsaved changes can offer to **Publish** them.
</Note>

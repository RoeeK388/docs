The Jurni editor is where you build and refine an experience's pages. Use the canvas to select content, the left toolbar to manage structure and tools, and the right panel to configure the selected section or element.

Open an existing experience from the **Experiences** area in Jurni, or [create an experience](/building-funnels/creating-a-funnel) first. You do not need to repeat onboarding to follow these editor guides.

## Check your scope before changing anything

Look at the current page, the selected section or element, and the editing indicators.

**Editing All Sizes** is the base/mobile editing mode. **Editing Desktop Only** is used for desktop-specific responsive adjustments. A **Global Section** is shared content, and a product page can separately show **Editing all products** or **Editing for: [product]**.

Those labels answer different questions. Confirm each relevant scope before changing a live purchasing area or reusable section.

## Header controls and review

The header contains the device/editing controls, Undo/Redo, comments, Settings, sharing, and publishing. Available preview controls also let you inspect, refresh, or expand the page preview. Some actions depend on your current page or editing mode.

| Task | Guide |
| --- | --- |
| Save work and distinguish canvas, preview, review, and live URLs | [Save and preview](/build/save-preview-publish) |
| Reverse an edit in the current session | [Undo and redo](/build/undo-redo) |
| Restore an available published snapshot | [Version history](/build/version-history) |
| Invite reviewers or copy a no-sign-in preview | [Share and review links](/build/share-review-links) |
| Add, reply to, resolve, and reopen feedback threads | [Comments](/product-updates/jurni-comments) |
| Validate the page before campaign traffic | [QA checklist](/building-funnels/qa-checklist) |

<Warning>
  Not every change has the same save behavior. Some Settings controls save directly; Global Sections have a shared-source save; and entering comments on a published experience with unsaved edits can prompt you to **Publish**. Read the action before confirming it.
</Warning>

## Publish to the intended environment

A working preview does not prove that every integration works on the final destination. Jurni-hosted pages and native Shopify Pages have different publishing and cart environments. Test the actual live URL and any Smart Link or experiment entry route before launch.

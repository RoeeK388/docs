A **Saved Section** is a reusable template in your shop's library. Insert it into a page when you want a copy you can adapt independently—for example, an approved hero layout or Buy Box that needs different content for each campaign.

For shared content that should stay connected across uses, see [Global Sections](/build/global-sections). These are different features, even though both are accessed from the Saved Sections panel.

## Save a section

<Steps>
  <Step title="Prepare the source section">
    Finish the section's content, styling, and behavior. Review both mobile and desktop. For a Buy Box, test the product and purchase configuration before saving it for reuse.
  </Step>
  <Step title="Select the whole section">
    Open **Layers** and select the section, rather than a single child element inside it.
  </Step>
  <Step title="Select Save Section">
    Open the section's more-options menu and choose **Save Section**. Wait for the save to finish.
  </Step>
  <Step title="Find the saved item">
    Open **Saved Sections** in the editor's left toolbar and select the **Saved** subtab. Use search to locate the reusable item.
  </Step>
</Steps>

## Insert it into another page

Open the destination experience in the **same shop**, select **Saved Sections → Saved**, choose the item, and use **Add Sections**. Locate the inserted section in Layers, move it into place, and customize it.

The inserted saved section is an independent copy, not a live shared reference. Changing that copy is not the same as updating every page that previously used the template.

## When to use Saved rather than Global

Use Saved Sections when your team wants the same starting layout with different copy, products, offers, or design adjustments on each page.

Use Global Sections when the content is meant to stay linked and you intentionally want to maintain a shared source. A campaign-specific Buy Box is often safer as a saved starting point unless the team deliberately wants that purchasing configuration shared.

## Recheck product and integration settings

A reusable layout can carry the source section's product IDs, action settings, review mappings, and custom behavior. After insertion, confirm the intended product, variants, selling plans, cart action, and widget provider.

Changing a visible product title does not remap the purchasing action. Make that change in the actual product or action control.

## Shops and regional stores

The reusable library is shop-specific. A section saved in one Jurni shop is not automatically a shared library item in a different UK, EU, or other regional shop.

When moving work between shops, have the source experience or section copied through the supported workflow, recheck the destination shop's products and integrations, and then save the section there. This is not automatic cross-shop synchronization.

## Maintain a useful library

Keep approved sections easy to identify and avoid many indistinguishable copies. Save tested, reusable patterns rather than unfinished experiments. Deleting an item from the library and removing a section from a page are separate operations; review what you are changing before doing either.

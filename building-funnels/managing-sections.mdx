Use the Section Library in the Experience Editor to add pre-built sections to a page. This guide covers how to open the library, add sections, and manage them on the canvas.

<Steps>
  <Step title="Open the Section Library">
    Open an experience in the Experience Editor. Use the **Sections** area to open the Section Library.
  </Step>
  <Step title="Browse or search for sections">
    The Section Library contains many pre-built sections organized into categories and layouts. Browse the categories or use search to find the layout you need. New sections are added over time.
  </Step>
  <Step title="Select and add sections">
    Select one or more sections, then click **Add Sections**. Sections are added to the canvas immediately.
  </Step>
</Steps>

## Where new sections appear

New sections are inserted below the currently selected section. If no section is selected, they are added at the bottom of the page. You can reposition sections after adding them.

## Selecting a section after adding

Click a section on the canvas, or select it from the section list. This opens the section's properties in the right-side editing panel so you can customize it.

<Warning>
  Sections are added through the Section Library, and multiple sections can be added at once. Saving is not automatic: save the experience draft, or update the published experience when you are ready to make those changes live.
</Warning>

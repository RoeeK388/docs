Add sections to build the page's structure without recreating each layout from scratch. Use the **Section Library** for a new pattern, **Saved Sections** for a reusable copy, **Global Sections** for shared content, and **Integrations** for provider widgets.

## Add a section from the library

<Steps>
  <Step title="Open the correct page">
    Open the experience in the editor and check which page you are editing. Finish any dedicated Global Section edit before adding content to the whole page.
  </Step>
  <Step title="Open Section Library">
    Select **Section Library** in the left toolbar. Browse the categories or search for the kind of section you need, such as a hero, FAQ, or Buy Box.
  </Step>
  <Step title="Select the section layouts">
    Select one or more templates. Selecting a template marks it for insertion; use the add action to insert your selection into the page.
  </Step>
  <Step title="Select Add Sections">
    Add the selected sections. Jurni clears the selection and returns to **Layers**, where you can locate the inserted sections.
  </Step>
  <Step title="Place and configure them">
    Check their position in Layers, reorder them as needed, and select each section to replace example content and configure its controls. Save the page changes when ready.
  </Step>
</Steps>

## Pick the right source

| Source | Use it for | Important distinction |
| --- | --- | --- |
| **Section Library** | Starting from a ready-made section layout. | A starting point still needs your content and configuration. |
| **Saved Sections → Saved** | Reusing a section as an independent copy. | Future local edits are not a shared global update. |
| **Saved Sections → Global** | Keeping a shared section connected across uses. | Editing the shared source has a wider impact. |
| **Integrations** | Placing reviews, forms, and other supported widgets. | Adding the section does not replace connecting the provider. |
| **AI** | Creating or adapting a section from instructions. | Review the result and its actual behavior before saving or publishing. |

## After adding a section

Replace sample copy and media, verify the selected product and button action, and inspect the layout in both mobile and desktop modes. For a Buy Box, choose the real product rather than leaving a visual placeholder.

If the section depends on a provider, product, or another section, configure that dependency too. For example, a review widget needs the right review provider/product mapping, and a scroll button needs a valid target.

## Common questions

**Why did nothing get added?** Confirm you selected at least one template and used **Add Sections**, rather than only browsing or searching.

**Why is the library unavailable?** In a dedicated Global Section edit, Jurni restricts the available panels. Finish that scoped edit and return to the page editor. Comment mode is also not an editing mode.

**Why does the section look empty?** Check required configuration, device visibility, and whether a product or widget provider has been connected. The standard Buy Box template, for example, does not render a live purchasing area without a selected product.

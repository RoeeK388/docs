A **Smart Link** is the URL you put in an ad, email, or campaign. Jurni manages what that URL opens, so you can change the destination without replacing the link everywhere it is used.

The three pieces have different jobs: the **page** is what shoppers see, the **Smart Link** is their campaign entry URL, and an **experiment** decides which variant an incoming visitor reaches when the link is used for a test.

## Create a link for a page

<Steps>
  <Step title="Open Smart Links">
    Open **Smart Links** in Jurni and start creating a link. You can also manage links from the experience's publishing flow.
  </Step>
  <Step title="Name the link and choose its URL slug">
    Use **Link Name** to identify it in your dashboard, such as “Paid social — Summer offer.” Set **URL Slug** to the campaign-facing path, such as `summer-offer`. These are different: renaming the link does not rename its URL.
  </Step>
  <Step title="Choose the destination">
    Select the Jurni experience or enter the supported destination URL. When creating a link from an experience, the destination may already be selected. Confirm that the intended page is published and accessible.
  </Step>
  <Step title="Add campaign parameters when needed">
    Set any fixed search parameters required for this link. Coordinate with the parameters already configured in your ad platform so the same field does not carry conflicting values.
  </Step>
  <Step title="Create and test">
    Select **Create Link**, then copy the saved Smart Link. Open it with the campaign parameters you intend to use and test the resulting page and purchase path.
  </Step>
</Steps>

<Note>
  In the Smart Links create/edit dialog, **URL Slug and the saved search parameters are locked after creation**. You can update the link's name and destination. Choose the permanent campaign URL before sharing it.
</Note>

## Which domain will it use?

With a connected Jurni custom subdomain, a link can look like `https://go.brand.com/summer-offer`. For standard Shopify stores without that subdomain, the fallback uses the store's app-proxy path, such as `https://brand.com/apps/jurni/summer-offer`.

Copy the URL Jurni generates rather than assembling one manually. A native Shopify Page at `/pages/summer-offer` is a possible destination, not the same thing as the Smart Link. See [Publishing overview](/publishing/overview).

## Use a link for an experiment

Set up the test through the [experiment creation flow](/experiments/create-experiment) and confirm the intended Smart Link is connected. Use that entry link in the campaign. Sending traffic directly to a variant page bypasses the test's assignment step.

To change an existing campaign, see [Change a Smart Link destination](/publishing/change-smart-link-destination). Do not assume selecting a page destination in the ordinary link dialog starts an experiment.

## Keep campaigns manageable

Reuse a link when it represents the same campaign purpose. Use separate links when different teams or campaigns need independent destination changes. Updating one shared link affects every placement that uses it.

For a used or unavailable slug, check the existing and archived links and follow [URL conflict troubleshooting](/troubleshooting/url-route-conflict). Archiving a link should not be treated as a guarantee that its slug is free to reuse.

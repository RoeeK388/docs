title: "Smart Links: Route Traffic Without Editing Campaign URLs"
sidebarTitle: "Smart Links"

---

Smart Links give you a stable URL that can route traffic to a Jurni experience or another destination. Instead of changing the URL in every ad, email, or campaign when the landing page changes, update the destination behind the Smart Link in Jurni.

## Why use a Smart Link

Smart Links are useful when you want to:

- Keep the campaign-facing URL stable
- Change the landing experience without editing every traffic source
- Route traffic into a Jurni experiment
- Replace or retire a destination without breaking existing campaign links
- Send traffic to a Jurni experience or supported custom URL

For paid media, avoiding unnecessary edits to a live ad can also reduce the chance that the ad needs to be reviewed or reprocessed by the advertising platform. The exact effect of an ad edit is controlled by that platform, not by Jurni.

## Create a Smart Link

<Steps>
  <Step title="Create the Smart Link">
    Open Smart Links in Jurni and create a new link.
  </Step>
  <Step title="Choose the destination">
    Select a published Jurni experience, an experiment, or a supported custom URL.
  </Step>
  <Step title="Copy the Smart Link URL">
    Use the Smart Link—not the underlying destination URL—as the campaign destination when you want future routing changes to happen inside Jurni.
  </Step>
  <Step title="Test before launch">
    Open the Smart Link in a new browser session and confirm it reaches the expected destination with the required campaign parameters intact.
  </Step>
</Steps>

## Change the destination later

Once the Smart Link is already used by a campaign, you can update its destination in Jurni without changing the Smart Link URL itself.

<Steps>
  <Step title="Open the Smart Link">
    Find the link in Jurni.
  </Step>
  <Step title="Choose the new destination">
    Select the replacement experience, experiment, or custom URL.
  </Step>
  <Step title="Save and verify">
    Save the routing change, then open the Smart Link and confirm new traffic resolves to the expected destination.
  </Step>
</Steps>

<Warning>
  Do not route meaningful traffic to a draft, unpublished, archived, or inaccessible destination. Verify the destination before changing a live Smart Link.
</Warning>

## Smart Links and experiments

Smart Links are commonly used as the traffic entry point for Jurni experiments. The campaign continues to use one stable Smart Link while Jurni handles variant assignment behind it.

This is especially useful when you want to compare:

- Two or more Jurni experiences
- A Jurni experience against an existing website page
- Different landing-page concepts without changing the campaign URL for every variant

## Campaign parameters

When your ads use UTMs or click identifiers, test that the required parameters remain available through the Smart Link flow. Common parameters include `utm_source`, `utm_campaign`, `fbclid`, and `gclid`.

Use the URL Parameters and UTM Attribution guides when routing depends on those values.

## Smart Link vs. direct destination URL

|  | Smart Link | Direct page URL |
| --- | --- | --- |
| Campaign-facing URL | Stays stable when Jurni routing changes | Must be edited when the destination changes |
| Destination control | Managed in Jurni | Managed at the traffic source |
| Experiments | Designed to work as an experiment entry point | Can be used for a single direct destination |
| Best for | Paid campaigns, testing, flexible routing | Static destinations unlikely to change |

## When to create a new Smart Link

Reuse a Smart Link when it represents the **same campaign or traffic purpose** and you are intentionally changing what sits behind it.

Create a separate Smart Link when you need independent routing, reporting, ownership, or campaign behavior. Keeping unrelated campaigns on separate links makes changes safer and easier to understand.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The Smart Link goes to the wrong page">
    Open the Smart Link in Jurni and confirm the currently saved destination. If it routes to an experiment, also check the experiment's active variants and traffic configuration.
  </Accordion>

  <Accordion title="The destination works directly but not through the Smart Link">
    Confirm the destination is published and publicly reachable, then test for redirect rules or parameters that behave differently when the request enters through the Smart Link.
  </Accordion>

  <Accordion title="My UTMs are missing">
    Follow the full redirect path and verify where the parameter disappears. Check custom redirects, external destinations, and any scripts that rewrite the URL.
  </Accordion>
</AccordionGroup>

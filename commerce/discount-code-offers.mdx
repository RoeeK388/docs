A **Discount Code** offer uses a code that already exists in your connected **Shopify store**. Jurni validates the code and uses it in the supported purchase flow. Create the discount itself in Shopify, not by typing a percentage into an AI prompt or a page heading.

## Get the code from Shopify

Open **Shopify admin → Discounts**, open the intended code-based discount, and copy the code exactly. Confirm its dates, qualifying products, minimum purchase, customer eligibility, purchase types, usage limits, and whether it can combine with other discounts.

An automatic discount with no code is not a value to paste into **Shopify Discount Code**. See [Shopify's discount-code guide](https://help.shopify.com/en/manual/discounts/discount-types).

## Configure the offer in Jurni

<Steps>
  <Step title="Create a Discount Code offer">
    Open **Offers**, create an offer, and select **Discount Code**. Give the offer an internal name.
  </Step>
  <Step title="Enter Shopify Discount Code">
    Paste the existing code and wait for validation. A recognized code displays its title. Resolve an invalid-code message before continuing.
  </Step>
  <Step title="Choose promotional display">
    **Show discount in storefronts** controls whether supported product and collection components show the promotion before the cart. When enabled, set **Display Text**, **Apply to**, and optionally **Show calculated price**.
  </Step>
  <Step title="Set scope and timing">
    Choose the intended experiences or **Global** for this Jurni shop. Add optional start/end timing and save the offer.
  </Step>
  <Step title="Test the final amount">
    Start on an included published experience and continue to checkout. Confirm the code is applied and the actual discount matches the message.
  </Step>
</Steps>

## Understand the display controls

| Control | What it does |
| --- | --- |
| **Show discount in storefronts** | Allows supported components to show the discount message before cart. Turning it off is not the same as disabling the offer's code. |
| **Display Text** | The promotional text, such as “Save 15% with code WELCOME.” |
| **Apply to** | Chooses **Both**, **One-time purchase only**, or **Subscription only** for the promotional message and calculated-price display. |
| **Show calculated price** | Displays a calculated promotional price in components that support it. |

<Warning>
The **Apply to** display control does not rewrite the discount's purchase-type eligibility in Shopify. The final code acceptance and amount still follow Shopify's rules. Custom Buy Boxes also need their displayed prices checked rather than assuming every design consumes these display settings.
</Warning>

## Common problems

**The code is invalid:** check the connected shop and exact code, and confirm it is a code-based discount in that Shopify store.

**The code is recognized but not applied to this cart:** check product, customer, date, minimum-purchase, subscription, usage-limit, and combination restrictions in Shopify.

**The page price differs from checkout:** review both the component's displayed price and the actual Shopify discount. Do not fix the difference by changing the displayed number alone.

For native Shopify Pages, external carts, or direct-checkout custom flows, test the exact destination. Do not assume this offer installs itself into every cart implementation.

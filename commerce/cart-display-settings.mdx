Use **Settings → Storefront Settings → Cart Settings** to configure the cart presentation used by the Jurni storefront. These are shop-level settings, not the layout controls for a single Buy Box.

<Note>
  This guide applies to the **Jurni cart**. A Shopify theme cart, Rebuy drawer, or custom/headless cart has its own settings. For a page published natively to Shopify, start with [Shopify Pages cart configuration](/shopify-pages/cart-config).
</Note>

## Available settings

| Setting | What it controls |
| --- | --- |
| **Cart title** | The heading at the top of the cart. |
| **Remove decimals from whole prices** | Whether whole prices display without trailing decimals; for example, `$20.00` becomes `$20`. This changes formatting, not the price charged. |
| **Show discount code field** | Whether shoppers can enter a discount code in the Jurni cart. The code still needs to be valid for the order. |
| **Show shipping calculator** | Whether the cart presents the shipping-estimate interface before checkout. |
| **Show prices on buttons** | Whether supported cart action buttons display the relevant price. |

## Update the cart

<Steps>
  <Step title="Open the correct shop">
    Check the shop switcher, then open **Settings → Storefront Settings**.
  </Step>
  <Step title="Find Cart Settings">
    Update the cart title and the display switches needed for your store.
  </Step>
  <Step title="Save this settings card">
    Select **Save Changes** in Cart Settings and wait for the saved confirmation. **Reset** discards unsaved changes in this card; it is not a rollback of your published page.
  </Step>
  <Step title="Test a page using the Jurni cart">
    Open the shopper-facing page, add the intended product, and inspect the cart. Check desktop and mobile, especially when the title or button content is long.
  </Step>
</Steps>

## Display settings do not create offers

Showing a discount field does not create a discount code or guarantee that codes can combine. Configure the actual discount in the commerce system and test its eligibility in cart and checkout.

Similarly, showing a shipping calculator does not create a free-shipping offer or change your shipping rules. Confirm the final checkout result for the shopper's country and selected products.

A displayed price on a button should agree with the shopper's selected purchase option and cart. Check one-time purchases and subscriptions separately when both are offered.

## Troubleshooting

**The cart did not change:** confirm that the page is opening the Jurni cart rather than a theme or third-party drawer. Confirm that you saved the correct shop's Cart Settings.

**The discount field is visible, but the code fails:** check the code's eligibility and combination rules. A presentation setting cannot override an invalid or ineligible code.

**Only one page behaves differently:** compare its purchase action and cart configuration with a page that works. Do not assume the two pages use the same cart just because they sell the same product.

Jurni analytics connect traffic, shopper behavior, commerce events, and experiment assignments so you can understand how each experience performs from landing through purchase.

## Core metrics

The main metrics you will see across Jurni include:

- Sessions
- Conversion rate (CVR)
- Revenue
- Average order value (AOV)
- Revenue per session (RPS)
- Add-to-cart rate
- Checkout rate
- Purchases / orders

For exact definitions and formulas, use the Metrics Glossary.

## Read the full conversion journey, not only the final conversion

A purchase is the final outcome, but intermediate steps help explain **why** performance changed.

A common conversion journey looks like:

`Session → Product interaction → Add to Cart → Checkout → Purchase`

If CVR falls, inspect the earlier steps:

- Low add-to-cart rate can point to product, offer, or page-message friction.
- Healthy add-to-cart with low checkout can point to cart friction.
- Healthy checkout with low purchase can point to checkout, payment, shipping, or discount issues.

## Filters and date ranges

Use the same date range and filters when comparing performance. Changing the date range, traffic source, or experience selection can materially change the result.

When comparing Jurni with another platform, also align:

- Timezone
- Attribution window
- Session definition
- Included traffic
- Consent state

## Experiments

Experiment analytics use the same commerce outcomes but break them down by variant. A valid experiment requires more than one variant having a higher number at a point in time—traffic allocation, sample size, duration, and the decision metric all matter.

## Attribution

Jurni maintains attribution context across supported Jurni-to-commerce flows. Third-party tools can report different totals because they use their own cookies, identity rules, consent handling, and attribution models.

<Info>
  Use Jurni analytics as the source of truth for Jurni experience and experiment performance, then use external analytics platforms to understand their own channel-specific view of the same traffic.
</Info>

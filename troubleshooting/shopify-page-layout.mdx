When a Jurni Shopify Page looks different from the Jurni editor, the cause is often the Shopify **page template** around the Jurni content rather than the experience itself.

## Symptom: the page is too narrow

Shopify themes frequently apply a maximum content width or horizontal margins to regular pages.

Check the **Jurni Funnel Page** app section in the Shopify theme editor for controls such as:

- Full page width
- Match section margins to theme
- Theme container width

If the Jurni design looks correct in the editor but the entire rendered experience is constrained, fix the Shopify template before changing the Jurni sections.

## Symptom: extra sections appear above or below Jurni

The page template may still contain default Shopify sections such as:

- Page title/banner
- Featured collection
- Newsletter
- Image sections
- Theme content blocks

Open the exact page template assigned to the Jurni page and hide or remove the sections you do not want.

## Symptom: header or footer is wrong

The theme template controls the Shopify shell around the Jurni app block. If the campaign requires a different header/footer treatment, create or use the appropriate dedicated Jurni page template rather than modifying the Jurni experience to compensate.

## Check the assigned template

A common mistake is editing one Shopify page template while the published page uses another.

<Steps>
  <Step title="Open the live Shopify page">
    Identify the page handle that Jurni published.
  </Step>
  <Step title="Check its template">
    In Shopify, confirm which page template is assigned to that page.
  </Step>
  <Step title="Edit that exact template">
    Verify the Jurni Funnel Page app section and its width/theme settings.
  </Step>
  <Step title="Save and reload">
    Save the Shopify theme changes and re-check the live page.
  </Step>
</Steps>

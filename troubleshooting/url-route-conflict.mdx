A page handle or Smart Link route must be unique within the domain scope where it is used. If Jurni says a route is unavailable, another active or previously created record may still own that path.

For example, if `/summer-sale` is already assigned, another page or Smart Link cannot safely claim the same route at the same time.

## Check visible destinations first

Search for the route across:

- Active Smart Links
- Active experiments
- Published experiences
- Shopify Pages when the conflict is on the Shopify URL
- Archived items available in your workspace

## Archived or removed routes

In some cases, an old or archived Smart Link can leave a route reserved even when it is no longer obvious in the main view. If you cannot find the owner of the route but Jurni still reports it as unavailable, contact Jurni support with:

- The full domain
- The exact route / handle
- The shop or workspace
- What you are trying to create

Jurni can check for archived, soft-deleted, or orphaned records and release the route when it is safe to do so.

<Warning>
Do not work around a route conflict by creating several near-identical URLs unless you actually want different permanent campaign URLs. It is better to clean up the intended route so campaign links stay predictable.
</Warning>

## Before reusing an old campaign route

Confirm that no active ads, emails, QR codes, creator links, or redirects still depend on the old behavior. Reusing a memorable route means old traffic can start reaching the new destination.

## Smart Link routing changes

If your goal is simply to send an existing campaign URL somewhere new, you usually do not need to create a new Smart Link route. Open the existing Smart Link and change its destination instead.

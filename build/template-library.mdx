Open **Library** from Jurni's main sidebar to start an experience from a reusable template. A template gives you a starting layout; you still need to review its content, select products, and configure the shopper's next action.

## Marketplace and My Templates

**Marketplace** contains the shared templates available in the library. **My Templates** contains templates saved for your current shop. Switch between them before searching for a design your team saved.

Use **Search Templates** to find a template by name. The available type filters depend on the collection and templates present. An empty **My Templates** view does not mean there are no Marketplace templates.

## Create an experience from a template

<Steps>
  <Step title="Open Library">
    Confirm the active shop, then open **Library** from the main sidebar.
  </Step>
  <Step title="Find a suitable template">
    Choose **Marketplace** or **My Templates**, search by name, and use the available type filters.
  </Step>
  <Step title="Select the template">
    Select its card, then use the create action at the bottom of the filter panel. Selecting the card alone does not create the experience.
  </Step>
  <Step title="Choose products and customize">
    When creation finishes, Jurni opens the new experience in the editor with product selection requested. Choose the appropriate products, replace sample content, and review every Buy Box and button action.
  </Step>
  <Step title="Save, review, and publish">
    Review mobile and desktop, test the actual purchase path, and publish to the intended destination when ready.
  </Step>
</Steps>

## Which reusable item do you need?

| Item | Best used for |
| --- | --- |
| **Library template** | Starting a new experience from a reusable page layout. |
| **Saved Section** | Inserting an independent copy of one section into an existing page. |
| **Global Section** | Keeping a shared section connected across its uses. |
| **Duplicate experience** | Starting a new draft from a particular existing experience. |
| **Asset** | Reusing an image or video rather than a page layout. |

Do not treat the Marketplace's shared template collection as the same feature as a **Global Section**. They solve different problems.

## Before reusing a campaign design

Review time-sensitive copy, prices, discounts, product availability, subscription choices, and links. Replace old promotion details even when the visual layout is still appropriate. A template is not evidence that an offer has been configured in Shopify or another commerce platform.

Creating a new experience from a template does not by itself point existing ads or Smart Links to it. Publish the new page, then deliberately update the campaign destination or add the new page as an experiment variant.

Use **Assets** in the main sidebar to organize the images and videos your team uses when building pages. Assets are media files; they are different from reusable page templates, Saved Sections, and Global Sections.

## Upload images and videos

<Steps>
  <Step title="Open Assets in the correct shop">
    Confirm the active brand, then open **Assets** from the sidebar.
  </Step>
  <Step title="Choose a destination">
    Open the folder where you want the files to appear, or stay outside a folder to add unassigned files.
  </Step>
  <Step title="Upload your files">
    Select **Upload or drop**, or drag files into the upload area. Wait for the upload to finish before selecting the new media in the editor.
  </Step>
  <Step title="Use the media on a page">
    Open the experience, select the image or video you want to change, and choose the uploaded asset through that element's media controls. Uploading a file to Assets does not automatically place it on a page.
  </Step>
</Steps>

Uploading while a folder is open places the uploaded files in that folder. The current Assets uploader accepts batches of up to **20 files**, with a **200 MB per-file upload limit**. These are upload limits, not recommended page file sizes. Prefer media sized for its actual display rather than unnecessarily large originals.

## Find an existing file

Use **Search media** and the image/video filters to narrow the library. Check which folder or view is open before assuming a file is missing.

| View | What it shows |
| --- | --- |
| **Unassigned files** | Media that is not currently assigned to a folder. |
| A named folder | Media assigned to that folder. |
| **All media** | Media across the library, including files in folders. |

**All files are in folders** does not mean the library is empty. Select **View all media** or open a folder. Clear search and file-type filters when the expected asset does not appear.

## Organize files into folders

Create a folder using the folder-creation control, then move files into it. Select files and use **Move to folder**, or drag a file onto a folder. When a selected file is part of a multi-selection, dragging it can move the selected set together, so check the selection count first.

Inside a folder, **Remove from folder** returns selected files to the unassigned view. This is an organization change, not a deletion of the files from the library.

Use names your team can recognize, such as a product range, campaign, or content type. Folder organization is for finding media; it does not apply a campaign tag, change product mapping, or update a page's design.

## Delete files from the library

Select the files, choose **Delete**, and review the confirmation. Jurni can show previous experience connections so you can inspect where those files have been used.

<Note>
  Deleting an asset through this library flow removes it from the media library. **Existing experiences are not changed by that action.** To remove or replace an image on a page, edit the page itself and publish the appropriate update.
</Note>

Deleting from Assets is therefore not a way to remove an outdated offer image from every live page. Use the displayed previous-usage information to find the pages that need editing, and verify each campaign destination afterward.

## Before publishing

Check that uploads completed, the intended file is selected, and images have a suitable crop in both desktop and mobile views. Test videos on the final page as well as in the editor. A library upload and a published page update are separate actions.

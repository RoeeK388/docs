Use locale editing to adapt an experience's text for a region. This guide applies to pages where localization is already configured; it is not a requirement for building your first page.

## Edit a locale

<Steps>
  <Step title="Open the page in the editor">
    Switch to the mobile view. When the page has configured locales, use the language control in the editor header.
  </Step>
  <Step title="Select the locale">
    Choose the region you need under **Current Locales**. Check the country label above the canvas before editing.
  </Step>
  <Step title="Update the copy">
    Select the text you want to change and enter the approved wording. Text edits in this mode apply to the selected locale. Check headlines, button labels, product descriptions, and any important offer terms.
  </Step>
  <Step title="Finish and review">
    Select **Done** to leave locale editing, then save or publish using the page's normal controls. Done exits the editing mode; it is not the Publish action. Review the localized page before sending traffic.
  </Step>
</Steps>

<Note>
  The desktop editing control is restricted while editing a locale. Finish the locale edit before returning to desktop layout adjustments.
</Note>

## Language and currency are different

Changing text does not set the shopper's currency, shipping eligibility, or checkout language. Those need to match your commerce and market configuration. For Shopify, see [Markets and currency](/commerce/shopify-markets-currency).

Before launching in another market, test the actual destination, product availability, prices, and checkout—not only the translated copy.

## Cannot find the language control?

Check that you are on a page with localization configured and in the mobile view. For your first localized experience, confirm the setup with the Jurni team. Do not assume creating a translated text version also configures regional traffic routing.

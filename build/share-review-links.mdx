The editor's **Share** control provides two different links: a restricted review link for collaboration, and a read-only **Preview Link** that does not require sign-in. Pick the link for the task, not just the first URL you see.

## Which link should you send?

| Need | Use | Access |
| --- | --- | --- |
| Let someone inspect the page without signing in | **Preview Link** | Read-only, no sign-in. Treat anyone with the link as able to view the preview. |
| Collect comments from teammates or invited clients | **Copy share link** | Only workspace members and invited reviewers can open it. |
| Send real campaign traffic | The published page URL or Smart Link | A preview/review link is not the campaign destination. |

## Invite a reviewer

<Steps>
  <Step title="Prepare the version to review">
    Save the draft and verify it in Preview. If the experience is already published, review the save/publish state carefully before making further changes live.
  </Step>
  <Step title="Open Share">
    Select the share icon in the editor header. Jurni loads the page's review link and access controls.
  </Step>
  <Step title="Invite the intended email">
    Use the reviewer invitation field for someone who is not already a workspace member. Have them use the email you invited and complete the invitation/sign-in flow shown to them.
  </Step>
  <Step title="Copy the review link">
    Select **Copy share link** and send it to the reviewer. Copying this URL alone does not grant access to an uninvited person.
  </Step>
  <Step title="Collect feedback in context">
    Ask the reviewer to leave comments on the relevant page content so feedback is tied to the section or element being discussed.
  </Step>
</Steps>

A reviewer invitation is not full shop membership. Use [Settings → Members](/getting-started/inviting-team-members) when someone needs to build or manage content in the shop.

## Manage reviewer access

Open Share to inspect the reviewer list. Use the available access-removal action when a reviewer should no longer have access, or resend an invitation when needed.

Check the email before resending. If the wrong person was invited, remove that access and invite the correct address instead of repeatedly forwarding the same invitation.

Removing a reviewer's access is not the same as protecting a separately shared public Preview Link. Treat the two link types independently.

## Why a reviewer cannot open the link

Check that you copied the share/review link for the correct experience, the person is a workspace member or invited reviewer, and they are using the intended account/email. A forwarded restricted link does not automatically authorize the new recipient.

If the goal is only a no-sign-in visual review, use Preview Link deliberately. Do not switch to that link to bypass an access requirement for confidential content.

## Good review instructions

Tell reviewers which version and device view to inspect and what kind of feedback you need. For example: “Review the mobile Buy Box and subscription choices. Comment on the exact control that needs changing; do not review the old campaign page.”

A comment records feedback. It does not automatically implement or publish the requested change.

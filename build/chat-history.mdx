Use **Chat History** to find an earlier conversation and continue the work. Chat history records the conversation; it is not a backup of the page at each message.

## Reopen an Agent conversation

Open **Agent**, then open **Chat History**. Select a conversation from the **Recent** list. Conversations without a title can appear as **Untitled chat**.

Some entries have an experience icon. Its tooltip identifies the connected experience. Opening one of these entries can redirect you to that experience's editor chat instead of leaving you in the standalone Agent view.

<Note>
  The history panel shows recent conversations. Do not interpret a conversation's absence from that list as proof that its associated page was deleted.
</Note>

## Continue a conversation in the editor

Open the intended experience and use **Chat history** in its AI panel. Continue the existing conversation when you are refining the same task. Use **New chat** when the next request is a separate task, and provide the relevant section, product, and reference context again.

Before continuing, check the page as it looks now. Other edits may have happened since the earlier messages. An old request such as “change the second section” may no longer identify the section you intend.

## Chat history is not page history

| What you need | Use |
| --- | --- |
| See previous prompts and replies | Chat History |
| Continue a page-building conversation | The existing chat, in Agent or its connected experience |
| Reverse an available editing action | [Undo/redo](/build/undo-redo) |
| Review or restore a previous published version | [Version history](/build/version-history) |
| Collect teammate feedback | [Comments](/product-updates/jurni-comments) or a [review link](/build/share-review-links) |

Opening an old conversation does not rewind the canvas. Repeating a creation request can also create additional work rather than recover the original page. Locate the experience first when the goal is to recover or continue an existing build.

## When a conversation seems missing

First confirm the signed-in email and active shop. A different account or shop can show a different set of work. Then check both the standalone Agent history and the AI history inside the relevant experience.

If the page still exists, open it before starting another build. If you still cannot find the conversation, share the experience URL, the email used, and the approximate time of the conversation with Jurni support. Do not include passwords, API secrets, or private payment details.

## When a response is interrupted

Inspect both the conversation and the canvas before retrying. Use the response's status or error message to understand what happened. Describe the unfinished change precisely instead of asking the Agent to repeat the entire build.

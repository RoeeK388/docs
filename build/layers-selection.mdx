Use **Layers** to understand what is on the page and select the part you want to edit. A section is a page-level block; inside it, individual elements can have their own text, media, styling, and behavior.

## Select before you edit

<Steps>
  <Step title="Check the page and editing mode">
    Confirm you are on the intended page and check whether the editor says **Editing All Sizes** or **Editing Desktop Only**.
  </Step>
  <Step title="Find the section">
    Open **Layers** in the left toolbar and select the relevant section. You can also select content on the canvas.
  </Step>
  <Step title="Select the element you need">
    For a specific text block, image, or button, select that element rather than the whole section. Use the layer structure where available when overlapping or nested elements are difficult to select on the canvas.
  </Step>
  <Step title="Read the contextual controls">
    The right panel changes with the selection. A section's configuration, an image's settings, and a button's action are different controls.
  </Step>
</Steps>

Selecting something to edit is different from activating it as a shopper. Use a [preview](/build/save-preview-publish) when you need to test a button, drawer, or modal instead of selecting it.

## Recognize the scope of the selected content

A normal section belongs to the current page. A **Global Section** references shared content. A product-page edit can also show an **Editing all products** or **Editing for: [product]** banner.

Before changing shared or product-specific content, read that indicator. A local section edit, a shared source edit, and a change to the product catalog do not have the same scope.

## Use the section menu

Open the section's **more-options menu** to see the actions available for that selection. Depending on the section, these can include **Save Section**, **Create Global**, **Apply Global**, **Detach Global**, **Copy**, **Cut**, **Paste**, **Duplicate**, **Rename**, **Hide/Show**, and **Delete**.

Not every action appears for every section or layer. Global references and older section types have different menus from a regular editable section. Use the available menu rather than assuming a missing action means the whole editor is broken.

## Rename sections for easier editing

For an ordinary section that supports renaming, use **Rename** or double-click its name in Layers. Prefer a descriptive name such as **Hero — subscription offer** or **FAQ — ingredients**.

This is an editor label, not necessarily the heading shoppers see. Rename the actual text element separately when you intend to change on-page copy. Global instances use their shared section name rather than an independent local label.

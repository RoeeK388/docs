Reorder page sections from **Layers** to change the order shoppers encounter them. Move the section itself when you want to move the complete block, rather than rearranging only an element inside it.

## Move a section

<Steps>
  <Step title="Open Layers">
    Open the correct page in the editor and select **Layers** from the left toolbar.
  </Step>
  <Step title="Find the section row">
    Locate the section by its name and select it to confirm the matching block on the canvas. Rename similar sections first if that makes them easier to distinguish.
  </Step>
  <Step title="Drag to the new position">
    Drag the section row above or below the other section rows, then release it at the intended position. Drag the row rather than an open menu or a name currently being edited.
  </Step>
  <Step title="Check the resulting page">
    Confirm the order on the canvas, inspect mobile and desktop, and save or publish through the appropriate action when the change is ready.
  </Step>
</Steps>

## What moving does not change

Moving a section changes its placement; it is not a request to rewrite its content or replace its product. Check the purchasing action separately when the new position changes how the shopper reaches the Buy Box.

A **Global Section** remains a shared reference after being moved. Its location in this page and its shared content are different concerns.

## Check the page after a move

Inspect the spacing between the moved section and its new neighbors. Also test buttons that scroll to a section and any sticky CTA that depends on the page's layout. The section order alone does not tell you whether a shopper interaction still behaves as intended.

A useful default structure is navigation/announcement, campaign message, product or education, supporting proof, FAQs, and the final action. Adapt that sequence to the page's purpose rather than inserting every section simply because it exists in the library.

## Troubleshooting

If dragging does not start, finish inline renaming or close the section menu and try the row again. Leave Comment mode before editing. If you are editing a single Global Section, finish that scoped edit before reorganizing the surrounding page.

For an accidental move, use [Undo](/build/undo-redo) while the change is still in the current editor history.

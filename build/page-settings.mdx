Select the **Settings gear** in the editor header to change settings for the current experience. This is different from the main dashboard's shop settings and from the design controls for an individual section.

## Find the setting you need

| Setting | Use it to |
| --- | --- |
| **Creator** | Choose whose content appears in creator-driven parts of the page. This is not a team-member setting. |
| **Subscriptions** | Set purchase preferences for components that use the experience-level subscription settings. See [Purchase options](/building-funnels/product-purchase-options). |
| **Cart → Enable Cart** | Show or hide the cart icon in the supported header. This does not clear the cart or disable checkout. |
| **Pop-ups** | Choose which connected providers are enabled for this experience. See [Pop-up controls](/build/page-popups). |
| **Variant Select Modal** | Choose **Default** or **Full Screen**. Full Screen also offers **Show product gallery**. |
| **SEO** | Set the page title, description, and preview image. See [SEO and sharing preview](/publishing/page-seo). |

Older experiences with an existing sticky banner also have controls for that banner. For new builds, follow [Sticky CTAs](/building-funnels/sticky-cta-banner).

Some settings appear only when the relevant feature or provider is configured. The pop-up control, for example, needs a connected supported provider.

## Save and check the result

<Warning>
  **Enable Cart** and **Enable SEO** save directly when changed. Other settings use their own **Save** button. On a live experience, treat these as potentially live changes—not only unsaved design edits.
</Warning>

Wait for confirmation, then test the result on the page. If a settings dialog will not close after an edit, use its Save or Cancel action.

Check purchasing behavior on the final live URL. Subscription preferences and variant-modal settings do not automatically replace the behavior of every custom Buy Box. For Shopify Pages, also check the actual Shopify publication.

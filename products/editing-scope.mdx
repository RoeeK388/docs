Before changing a purchasing page, identify **what you are editing and which other pages use it**. A local headline, shared product content, and a reusable purchasing layout do not have the same scope.

## Choose the right place for the change

| Change you need | Where to make it | What else to check |
| --- | --- | --- |
| Change one campaign's headline, image, or section spacing | The local page section in the editor. | Check that it is not a Global Section and review both screen sizes. |
| Update approved product benefits, detail text, or variant media | **Products → Edit Product Data**. | Other experiences with components that read this product data can use the new information. |
| Maintain the same section across several pages | The relevant Global Section editing flow. | Read the shared-save warning; an update is not private to the page you opened. |
| Start from a reusable design but edit each copy independently | Insert a Saved Section. | Recheck product, link, and review identifiers for the new page. |
| Change the real item price, variant availability, or subscription plan | Shopify or the connected commerce system. | Test the cart/checkout; typed page text does not change the real purchase. |
| Change a discount or gift's qualification | Main **Offers** area and the corresponding Shopify rule. | The product drawer's Offers tab contains promotional content, not the discount engine. |

## Make a campaign-specific version

For a local section, edit that page normally. For a standard Global Section, use **Detach Global** when you need an independent occurrence, then verify it is no longer shared before editing.

Do not assume every purchasing workflow exposes Detach Global. If the section opens a dedicated Buy Box management view with a shared-update warning, stop and create a separate version using the controls available for that flow. Duplicating the page alone does not prove its shared purchasing content became independent.

## Change a shared section deliberately

Check the shared section's name and intended uses. Make the update, preview the relevant product choices and both device layouts, then read the confirmation before saving.

For Shopify Pages, update the Shopify publication and inspect the actual `/pages/` destination. A shared Jurni source and a separately published Shopify page are not the same saved artifact.

## Reuse a design for another product

Use a reusable starting design, select the new product, and inspect the entire purchasing area. Check variants, plans, quantities, images, review product IDs/SKUs, discounts, gifts, and the purchase action.

A section looking correct is not enough: a review widget or custom button may still point to the previous product.

## A safe AI edit

> Change only the selected page section's spacing and media layout. Preserve the product, variant and subscription selectors, quantities, prices, and cart/checkout action. Do not change shared product data or other pages.

A prompt is an instruction, not a substitute for checking the edit scope and actual result.

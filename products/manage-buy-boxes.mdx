A **managed Buy Box** is a saved purchasing layout connected to a product. A product can have several named Buy Boxes, and more than one page can use the same Buy Box.

For example, a hydration product could have a standard Buy Box and a separate subscription-focused Buy Box. The campaign page chooses which one to use. You do not need a duplicate Shopify product just to use another purchasing design.

## Understand the three choices

| Item | What it means |
| --- | --- |
| **Product** | The real catalogue item, its variants, and its available purchase plans. |
| **Buy Box** | A named, product-specific purchasing layout that pages can share. |
| **Buy Box template** | A starting layout for creating another Buy Box. It is not yet tied to the new product. |

Adding the same saved Buy Box to another page creates another connected use—not an independent copy of its design.

## Add an existing Buy Box to a page

<Steps>
  <Step title="Open the Buy Box area">
    Open the experience editor and the Buy Box area in **Section Library**. Select the intended product before choosing its purchasing layout.
  </Step>
  <Step title="Choose the product's Buy Box">
    Select an existing saved Buy Box for that product. The product's default is a starting choice; choose another version when the campaign calls for it.
  </Step>
  <Step title="Add it to the page">
    Use the available add-to-page action. On an inserted managed Buy Box, the right panel separates **Product** from **Buy Box**. Confirm both before reviewing the design.
  </Step>
  <Step title="Verify the selection">
    Preview the page and test its important variant and subscription choices. Inspect the real item, quantity, plan, and total in cart or checkout, then publish the page through the intended publishing path.
  </Step>
</Steps>

## Create a new Buy Box

<Steps>
  <Step title="Choose Create new">
    Start a new Buy Box and choose the real product. Give the finished version a useful name, such as “Hydration — subscription focus,” rather than a generic version number.
  </Step>
  <Step title="Select the starting template">
    Choose a Jurni template or a saved Buy Box template. Complete the product and template selection before editing; an empty setup screen is not a completed purchasing section.
  </Step>
  <Step title="Customize with AI or visual controls">
    Work on the Buy Box in its dedicated editing view. Explain the desired design and which purchase choices must remain unchanged. Check mobile and desktop, not just the first canvas view.
  </Step>
  <Step title="Create the saved Buy Box">
    Use **Create** to save the new product-specific Buy Box. This is separate from publishing the whole campaign page.
  </Step>
  <Step title="Use it on the page">
    Add the saved version through **Add Buy Box to page** or select it in an existing managed section. Save/publish the page and verify the final destination.
  </Step>
</Steps>

## Edit an existing Buy Box

Select the managed purchasing section and choose **Manage**. Confirm the product and Buy Box name in the editing header, and check the connected-page count before changing anything.

Use **Save** for an existing Buy Box. When it is already used by pages, the confirmation warns that the shared update affects its connected uses. For a change intended only for one campaign, use a separate Buy Box version rather than saving over a shared one.

Switching products or Buy Boxes while editing can prompt you to discard unsaved work. Save the version you intend to keep before navigating away.

## A useful AI request

> Redesign this Buy Box for [campaign/audience]. Use the selected product and approved product information. Keep the available variants, subscription plans, quantity rules, and purchase action working. Change only [layout/copy/visual details]. Do not invent a discount or turn working selectors into static buttons.

If the purchase behavior itself must change, state it separately and test the resulting cart/checkout. A subscription card needs a real plan; a savings badge needs the corresponding pricing or discount.

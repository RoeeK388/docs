Use **Products → Edit Product Data** to maintain reusable information for a product. Supported page components can use this information across experiences, so this is different from editing one paragraph on one landing page.

## Open and save product data

<Steps>
  <Step title="Find the product">
    Open **Products** in the correct shop, search for the product, and open **Edit Product Data**.
  </Step>
  <Step title="Choose the relevant tab">
    Use the tabs below to edit the information you need. Keep the real product, variant, and subscription setup in your commerce platform.
  </Step>
  <Step title="Save Changes">
    Select **Save Changes** at the bottom of the drawer. **Cancel** leaves without saving those form changes. A separate media-selection dialog may also need confirmation before the overall product save.
  </Step>
  <Step title="Check a page that uses it">
    Open a relevant page and confirm the component reads the updated product data. Static text written directly into a section is not automatically replaced by a product-data update.
  </Step>
</Steps>

## What each tab does

| Tab | What you can maintain |
| --- | --- |
| **Variants** | Swatch presentation for existing options and linked-product options supported by the purchasing component. This does not create Shopify variants. |
| **Benefits** | Reusable benefit text and icons. |
| **Details** | Supporting product information and accordion questions/answers. **Custom URL** can override the default product-page navigation used by compatible components. |
| **Reviews** | Curated review content and related presentation information. This is separate from a live Okendo, Yotpo, or other provider widget. Only use real, approved review material. |
| **Offers** | Promotional content such as a title, description, badge, button text, and link. **This is not the main Offers area and does not create a checkout discount.** |
| **Cross-Sell** | Related product selections for components that use that product information. This does not add a configurable upsell to every cart. |
| **Variant Media** | The media selection and order for each variant. |

## Set media for a variant

Open **Variant Media**, choose the variant, and select its images/videos from the available product media, shop assets, or supported URL input. Reorder the selected media to put the most useful view first, confirm the selection, and save the product.

**Always include main variant image** keeps the variant's main image first even when custom media is selected. When it is off, the custom selection controls that variant's media. Test by changing the actual product option on a page that uses variant media.

## Use Sync Product deliberately

**Sync Product** starts a separate process to retrieve product content. It is not the same as **Save Changes**, and starting it does not mean every field has already refreshed. Review the result before using it in a campaign, especially approved benefits and claims.

If the problem is a missing Shopify product, price, or selling plan, first check its catalogue availability and source configuration. Do not assume the content-sync button fixes every commerce connection problem.

## Choose the correct scope

For a one-page campaign headline, edit that page. For reusable product information, edit Product Data. For an offer's qualification, use [Offers](/commerce/offers-overview). For a shared layout change, review the [editing-scope guide](/products/editing-scope) before saving.

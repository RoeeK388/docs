# Academy vs. Help Center

Use **Academy** when you want to learn a complete marketing workflow. Use the **Help Center** when you already know what you want to do and need the exact Jurni steps.

| If you're asking… | Go to… |
| --- | --- |
| “How should I turn this ad into a landing page?” | Academy playbook |
| “How do I create a Smart Link?” | Help Center |
| “What should I test on this page?” | Academy playbook |
| “How do I create an experiment?” | Help Center |
| “How do I prompt Jurni to recreate this reference?” | Academy Prompting 101 / Prompt Library |
| “Where do I connect Figma?” | Help Center |
| “How should I structure an advertorial?” | Academy |
| “How do I publish to Shopify Pages?” | Help Center |

Academy lessons link into the Help Center when a workflow reaches a product control that needs exact setup. Help Center articles link back to Academy when strategy, examples, or a full playbook would help.

This separation keeps product support concise while still giving customers a deep learning resource.

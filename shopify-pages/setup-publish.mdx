Publish to **Shopify Pages** when you want a Jurni-built page at `yourstore.com/pages/your-handle`, inside your Shopify Online Store. Keep editing the page in Jurni, then update its Shopify publication when your changes are ready.

<Note>
  This is optional for Shopify Online Store brands. A Jurni custom subdomain or the default `/apps/jurni/` URL is a different publishing path. Headless and non-Shopify storefronts should follow their [platform setup](/getting-started/choose-your-setup).
</Note>

## Before you begin

Connect the correct Shopify store and have someone with permission to edit its theme and approve app permissions available. Review the [Shopify Pages limitations](/shopify-pages/limitations), especially for custom carts and third-party widgets.

## 1. Prepare your Shopify theme

The setup dialog in Jurni walks you through these steps. You only need to prepare the template once for the theme you will use.

<Steps>
  <Step title="Create a page template">
    In Shopify, open **Online Store → Themes → Customize**. Create a **page template** named `jurni-funnel` in the intended theme. Do not edit the template used by unrelated store pages.
  </Step>
  <Step title="Add the Jurni app block">
    In that template, add **Jurni Funnel Page** from the theme editor's Apps section. This is the app block's actual name in Shopify.
  </Step>
  <Step title="Check the surrounding layout">
    Remove or hide unwanted default content in this template. In the Jurni block settings, disable **Match section margins to theme**. Check any additional width controls provided by your theme.
  </Step>
  <Step title="Save and complete the connection">
    Save the template in Shopify. Return to Jurni and use **Enable Shopify Pages** in the setup dialog. Approve additional app permissions if requested, then complete the return/refresh step. The dialog can show **Yes, I'm done** after the connection handoff.
  </Step>
</Steps>

For additional templates and theme changes, see [Shopify page templates](/shopify-pages/page-templates).

## 2. Publish your page

Open the experience in Jurni, then **Publish → Publish to Shopify**. Complete the setup above if Jurni displays it first.

| Field | What to do |
| --- | --- |
| **Store** | Confirm this is the correct connected store. |
| **Page Handle** | Enter the part after `/pages/`, such as `summer-offer`. Check the resulting URL before publishing. |
| **Page Layout** | Choose which parts of the Shopify theme surround the Jurni page. |
| **Page Template**, when shown | Select the prepared template. The picker appears when another template is available; its absence is not necessarily a setup problem. |

The Page Layout options are **Full Theme (Header + Footer)**, **Header Only**, **Footer Only**, and **No Theme**. Use the option that avoids duplicating navigation or a footer already included in your Jurni design.

Select **Publish to Shopify**, wait for completion, and open the published URL.

<Warning>
  The Page Handle is locked in this publishing panel after publication. Choose it carefully. For a live URL change, arrange the replacement and any needed redirects before changing campaign links; do not unpublish an active campaign merely to experiment with its handle.
</Warning>

## 3. Check the real Shopify page

Open the `/pages/` URL on desktop and mobile. Check the page width, header/footer, images, button destinations, product selections, cart, and checkout. Test the required pixels, consent behavior, forms, and review widgets there—not only in Jurni Preview.

A cart drawer may need [Shopify Pages cart configuration](/shopify-pages/cart-config). Theme or app installations can also duplicate tracking already added elsewhere.

## Update an existing publication

Make your changes in Jurni and reopen the Shopify publishing panel. Select **Update** to send the changes to the existing Shopify page. Layout or template changes can also require an update.

If **Update** is disabled, first check whether there are any page, layout, or template changes to publish. Reopen the live URL after a successful update and verify the changed area.

## Stop using a Shopify page

Move or pause any traffic using the page before selecting **Unpublish page from Shopify** and confirming the action. Unpublishing is not the same as changing a Smart Link's destination, and it does not update URLs already used in ads or emails for you.

See [Update or unpublish](/publishing/update-unpublish) for the broader campaign checklist.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The connection or permissions check fails">
    Confirm the correct store, the requested app permissions, and that the prepared template was saved in the intended theme. Complete the connection flow and return to Jurni before retrying.
  </Accordion>

  <Accordion title="The page is too narrow or has extra content">
    Check the selected template and block width settings, then the Page Layout choice. Use the [layout troubleshooting guide](/troubleshooting/shopify-page-layout) rather than changing unrelated templates.
  </Accordion>

  <Accordion title="Publishing reports an unsupported section">
    Keep the error message and identify the affected section. Replace or update it, or share the message and experience link with Jurni support. Do not assume the existing live page contains an update that failed to publish.
  </Accordion>
</AccordionGroup>
